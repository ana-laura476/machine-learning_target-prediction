# random-forests_target-prediction

* input_data.csv contains the full dataset with all targets, annotated pactivity values, and molecules in CATS2 descriptors (supervised learning).
* input_data_unsupervised.csv contains the full dataset with all targets, and molecules in CATS2 descriptors (unsupervised learning).
* data_base_caracterization.csv has all information regarding the targets and pactivity ranges (supervised learning)
* each folder contains the scripts used to assess predictive performance, for each algorithm
